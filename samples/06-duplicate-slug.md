# Introduction to Limits

This document carries the same title, and the same explicit slug, as
`01-plain.md`. Uploading it after `01-plain.md` must be refused with a message
saying the slug is already taken.

Because doc slugs are globally unique and immutable (brainstorm 5.4), the
single-upload path rejects the collision rather than renaming it. The bulk
import path is different: there a duplicate title becomes `-2`.
