# Limits

The limit of a function describes the value it approaches as its input
approaches some point. We write $\lim_{x \to a} f(x) = L$ when $f(x)$ can be made
as close to $L$ as we like by taking $x$ close enough to $a$.

A function can have a limit at a point where it is not even defined.

## One-sided limits

The left-hand limit and the right-hand limit may differ. The two-sided limit
exists only when they agree.
